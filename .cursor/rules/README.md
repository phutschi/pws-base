# Cursor Rules - pws-base

Concise, actionable coding rules for the pws-base Next.js + tRPC monorepo.

## Files

- **overview.mdc** - Project overview and tech stack
- **architecture.mdc** - Monorepo structure and dependency rules
- **typescript.mdc** - TypeScript standards and patterns
- **trpc.mdc** - tRPC router patterns and API design
- **database.mdc** - Drizzle ORM and database patterns
- **react.mdc** - React component patterns (server/client)
- **ui-components.mdc** - UI component patterns (Radix + CVA)
- **error-handling.mdc** - Error handling and logging
- **auth.mdc** - Authentication and authorization
- **security.mdc** - Security guidelines
- **performance.mdc** - Performance optimization
- **testing.mdc** - Testing patterns
- **conventions.mdc** - Naming and code organization
- **recipes.mdc** - Common tasks and workflows
- **quick-reference.mdc** - Quick lookup reference

## Core Principles

✅ End-to-end type safety
✅ Strict validation everywhere
✅ Server Components first
✅ Structured logging
✅ Protected by default
✅ Performance-first

## Usage

These rules guide your IDE's AI to follow project patterns and conventions. Each file focuses on a specific domain for quick reference.
